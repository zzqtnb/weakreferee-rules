# 变更记录

只写「换到这一版会有什么不同」，不写内部重构过程。

## 0.4.0 — 2026-11-25

这一版改的是「怎么用它」，闸的判断逻辑本身没动。装上后行为有五点不同：

- 面板每条判据多了三档：拦、只提示、按包里默认。点完只写安装清单（`data/judges-installed.json` 的 `actions`），不动包里的 `rules.json`，包升级冲不掉
- 面板多一栏「库里」：整份判据库逐条列出来，装进闸的能调档，还没写成机器判据的显示灰卡并标「还没写成规则」。判据能单条删掉，删掉的进「已删」栏，点恢复就回来
- DSH 界面左侧多一个入口，直接打开判据面板；面板服务由插件托管，已经在跑的不另起一个
- 判据 34 条变 36 条（core 加「派活没写验收」，dsh-host 加「按坐标点页面前没截图」），展开 483 变 485；判据库说明 39 条变 42 条
- 新增 `judge-packs.cjs export`：把四个包连同判据库说明按版本号导成发布目录，只读源文件，`data/` 一条不进

入库口径写死进校验：实测档必须写明是哪个模型犯过；本机拦下的写「DSH 模型犯过 N 次」——DSH 背后就是模型，本机拦下就是它犯的，不另算一类。
## 0.3.0 — 2026-11-23

判据从手写改由底稿生成，闸本身也动了两处，装上后行为有三点变化：

- 拦下时会把同一调用命中的其它判据一并带出来（以前只报最凶的那条，剩下的看不见）。返回里多一个 `notes` 字段
- 判据代码比宿主新时（改了判据没重启），每进程只拦一次，之后每 50 次记一行「P6 仍在（已静默 N 次）」。以前是一次不落地全刷进账本，一周两千多条，把别的判据全淹了
- 规则从 13 条变 14 条：补上 P6（判据代码比宿主新）与 BAT（往 `.bat`/`.cmd` 写中文会乱码），`windows-powershell` 包 8 条变 9 条

引擎内部另有两处：规则按工具名分桶（一次调用只过相关的那几条），环境变量支持默认值 `{DSH_JUDGE_TOOLS_DIR|SELF_LIB}`——变量没设就用包内 `lib\`，不再因为缺一个变量整条规则被拒装。

还有一处是给别人用的：备份目录与自查标记原来写死了本机绝对路径（某个盘下的回收站与状态目录），别人机器上没有那个盘就静默失效。现在默认落插件自己的 `data\`，可用 `DSH_JUDGE_DATA` / `DSH_JUDGE_BACKUP` / `DSH_JUDGE_MARKS` 覆盖；备份写不进时会在判定里明说「这次没备份」，不再假装备了。

## 0.2.0 — 2026-11-22

- 全部本机绝对路径清掉，判定、规则、契约表都从包自己所在的目录找
- 日志落点改成六档候选：配置 → `DSH_JUDGE_LOG` → 包内 `data\` → `DSH_HOME\logs` → 用户目录 → 临时目录。全写不进就在启动日志里喊一句，不假装记上了
- 新增 `install.ps1`（装 / `-Uninstall` / `-DryRun`），改 profile 前先备份 `package.json`
- `check.cjs` 并排打印「主判定 / 新引擎 / 一致」，规则包与主判定表可以互相对账

## 0.1.0 — 2026-11-19

首版。一次工具调用 dispatch 前同步核参数形态，拦下即拒，其余只记账。
