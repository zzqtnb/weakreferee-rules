# 跟同类项目差在哪

写这份文档的原因：任何人看到「AI agent 工具调用前检查」这个描述，第一反应都是「哦，又一个是 agent firewall」。
所以这里把话说明白——**我们跟它们不是同一层，可叠加，不替代**。

检索时间：2026-11-22。星数为当日。

## 它们在做的事

| 项目 | 星 | 语言 | 自述 | 抓什么 |
|---|---|---|---|---|
| [avakill](https://github.com/log-bell/avakill) | 26 | Python | 「One YAML policy. Three independent enforcement paths.」 | 命令该不该跑；不调模型、不联网、<1ms |
| [hol-guard](https://github.com/hashgraph-online/hol-guard) | 1118 | Rust | 「Open-Source Antivirus for AI Agents」 | shell 命令、文件访问、包安装、MCP 调用 |
| [Doberman-Core](https://github.com/DobermanCore/Doberman-Core) | 240 | Python | 「A guardrail that isn't on the execution path can only advise.」 | 每个调用运行前的唯一裁决 |
| [cordum](https://github.com/cordum-io/cordum) | 508 | Go | source-available 控制平面 | 策略检查、人工审批、审计 |

Doberman 那句立论值得单独抄一遍：**不在执行路径上的护栏只能提建议**。本仓库同意这句话，并且也是在做执行路径上的拦截。

## 差别不在「谁更强」，在「抓的是不是同一类错」

把 AI 的错分两类：

| 类别 | 特征 | 谁在管 |
|---|---|---|
| **策略层**：该不该做 | 没有标准答案，取决于场景、权限、风险偏好 | avakill / hol-guard / Doberman / cordum |
| **机械层**：做得对不对 | 有明确答案，可以对错 | **本仓库** |

「删掉生产数据库」是策略层问题——在很多场景下删库是合法操作，只是这次不该删。
「必填参数少了一个」是机械层问题——没有任何场景下这是对的。

前者必须靠策略和人工审批，后者可以靠判据自动判定。**两类都需要，但工具不同。**

## 四条可核对的差别

### 1. 分发形态

它们分发**策略文件**或**内置安全清单**。

本仓库分发**规则包**，每个包带两样东西：

- `testedOn`：在哪台宿主、哪个模型、多少次调用上验过，命中几次
- `selfTest`：装之前跑一遍正反例，一条不过就不让装

一条规矩写着「在 18,360 次真实调用上命中 29 次」，和一条写着「我觉得应该这么写」，价值差一个量级。这个差别不是靠文档说出来的，是靠字段强制记录下来的。

### 2. 规则从哪来

它们的规则由安全专家预置，覆盖的是「已知的危险命令模式」。

本仓库的规则**全部来自一次真实的开发事故**。举例：

- 一条规矩的来源是「往 .ps1 写中文没带 BOM，PowerShell 5.1 按 ANSI 读，整篇乱码」
- 另一条的来源是「改了判据代码但没重启宿主，闸跑的还是旧逻辑，而且不报错、继续显示通过」——这类失效最阴，因为它看起来一切正常

每条的 `evidence.source` 里写着命中时间戳。**能追到具体哪一秒，这是它跟「专家预置」最大的不同。**

### 3. 动作前快照与回退

它们提供拦截与人工审批——**事前不让你做**。

本仓库除了拦，还在动手前**存一份快照**，允许退回上一步。原理很土：回退只能靠事前备份，事后补救不了。

配套的三种退法（退上一次 / 退到第 N 轮开始 / 只还原某个文件），以及四条事前声明的触发条件——不是出事后再问「要退到哪」，而是开工前就把规矩说清。

### 4. 不绑 MCP

它们的拦截点大多在 MCP 层。本仓库的拦截点在宿主自己的工具派发处，所以一个不用 MCP、直接调函数的环境也能用。

这不是优劣，是覆盖面不同的取舍：绑 MCP 换来的是容易接入，代价是管不到不走 MCP 的调用。

## 必须承认的三件事

1. **本仓库不是首创。** 「引擎不变、规则可换」这个模式在安全领域成熟得很：OPA/Rego、Cedar、Semgrep 都是这个思路。本仓库的贡献只在场景（AI 工具调用）与时点（执行之前），不在范式。
2. **规模小。** 13 条规则、18,360 次调用、一个模型、一台机器、一个人。这个规模能证明「机制可行」，证明不了「普遍有效」。
3. **跨模型尚未测。** 现有数据全部来自单一模型。判据分三层（通用/平台/宿主），其中平台层与宿主层换环境就会失效，这一点写在包里，没有藏。

## 一句话总结

> 它们在管「AI 要不要动」，我们在管「AI 动的时候手抖没抖」。
> 前者靠策略，后者靠判据；两者都缺不得。
