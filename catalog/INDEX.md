# 判据库

一条一句，挑你要的那几条。这里只写「检查什么、什么时候会撞上、撞上了怎么办」，**具体的判定写在 `packs/` 里**——库里不放正则，就不会出现两份说法对不上的情况。

共 **22 条**，铺满 7 个域。动作三档：**拦下**（拒了这次调用）、**提醒**（放行但记一笔）、**记账**（只写日志，不打断）。表里的动作是**默认值**，装到你自己机器上想怎么调都行，改法见 `CONTRIBUTING.md`。

**状态有两种**：「已进包」的现在就会判；「待引擎」的只登记了说明——要么需要跨调用记住上下文，要么需要读懂语义，现在的判定层还做不到，等引擎补上能力再升成真判据。

## 人群标签

每条都挂着「主要服务谁」。人群**只用来挑包**，不影响判定——同一条规矩，程序员装上和学生装上跑的是同一段代码。挑包见 `packs/`。

| 标签 | 中文 | 典型场景 |
|---|---|---|
| `dev` | 写代码改文件 | 改脚本、改配置、跑测试、提交 |
| `student` | 作业论文报告 | 写论文、查文献、交课程作业 |
| `writer` | 写小说 | 长篇连载、设定一致性、一章一章往前推 |
| `research` | 查资料做调研 | 搜资料、比对来源、写调研稿 |
| `office` | 办公文档表格 | Word、Excel、报表、PPT |
| `ops` | 装环境运维 | 装软件、改服务、清磁盘、连服务器 |
| `chat` | 只聊天问答 | 不碰文件，纯问答与写东西 |
| `general` | 通用 | 谁都可能踩，不分职业 |
